## Implementation

Work the unblocked issue frontier. Read the complete issue and comments, claim
the ticket, make the bounded change, verify it, and record the result on the
ticket. User instructions and already-authorized work take precedence over
generic workflow prompts; ask only for decisions that remain unresolved.

For catalogue analysis, preserve raw chart/audio identities and learner
practice/feedback storage. Existing algorithm settings and evidence are frozen;
read `docs/ALGORITHM_SELECTION.md` before changing the selected workflow.
Editorial drafts and model agreement are not independent timing references.

Keep media, model weights, generated caches and private review sessions ignored.
Link the originating issue from a focused PR; close it when its acceptance
criteria are evidenced. Keep production deployment and source pushes distinct.
